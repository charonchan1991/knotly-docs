This repository contains the documentation source for [**Knotly**](https://www.knotly.com/), an online 3D crochet and amigurumi simulator. The files here provide the source content for Knotly’s user documentation.

## Reporting documentation issues

Please report documentation errors, missing information, or unclear instructions through this repository’s **GitHub Issues**. Include the affected page or topic, describe the problem, and suggest a correction if you have one. This helps the Knotly team review and track documentation improvements.

## Reporting Knotly bugs and sharing feedback

Use this repository’s **GitHub Discussions** to submit bugs and provide feedback on the Knotly application. You can share suggestions, describe your experience, or discuss improvements you would like to see. When reporting a bug, include the steps to reproduce it, what you expected to happen, and what actually happened. Screenshots and details about your browser or device can also help the Knotly team investigate.

## Maintaining the documentation

Documentation changes are maintained internally by the Knotly team. GitHub Issues are the public channel for reporting documentation problems and suggesting documentation improvements; the team reviews that feedback and manages updates to the source internally.

## Published documentation

The published documentation is rendered by the **Knotly application**. This repository holds its source content, while the application presents that content as the user-facing documentation. To read the published documentation in its intended context, see [Knotly documentation](https://www.knotly.com/docs).
